# Интиллектуальная обработка гиперспектральной мозаики снимков
Плагин QGIS 3 для подготовки гиперспектральной мозаики из снимков с дрона и заполнения пропусков (NoData) в растрах. Этот репозиторий хранит исходный код программы, реализованной в рамках выпускной квалификационной работы СПбГУ, ф-т ПМ-ПУ, кафедра технологий программирования.

## Назначение

Плагин решает 4 связанные задачи обработки гиперспектральных аэрофотоснимков:

1. Геопривязка исходных изображений;
1. Отбраковка непригодных растров;
2. Мозаицирование;
3. Заполнение внутренних пропусков (NoData) в результирующем растре.

Плагин сохраняет исходные спектральные значения пикселей, даже если это приводит к видимым швам в перекрывающихся областях кадров.

## Основные инструменты

Плагин предоставляет 6 алгоритмов в Processing Toolbox:

1. **Filter bad frames** — отбраковка некачественных кадров
2. **Airborne georeference** — геопривязка сырых гиперспектральных данных
3. **Mosaic frames** — сборка кадров в мозаику с сохранением спектральной верности
4. **Fill nodata** — заполнение пропусков без изменения корректных пикселей
5. **Mosaic quality** — оценка качества мозаики по сравнению с эталоном
6. **Hyperspectral pipeline** — сквозная обработка от фильтрации до заполнения пропусков

## Важный принцип

**Спектральная верность**: каждый пиксель в выходной мозаике берется из ровно одного исходного кадра. При заполнении пропусков создаются новые значения только в областях, где их не было, без изменения оригинальных данных.

## Архитектура

Логика плагина разделена на две части:
- Ядро в папке `src/` — чистый Python без зависимостей от QGIS
- Обёртки в корне проекта — интеграция с QGIS Processing

## Входные данные

- Гиперспектральные кадры (GeoTIFF)
- Опционально: сырые данные камеры (.bil) с файлами калибровки (.hdr, .lcf, .times)
- Опционально: цифровая модель рельефа (DEM) для точной геопривязки

## Использование

1. Установите плагин через *Plugins → Manage and Install Plugins*
2. Откройте *Processing Toolbox*
3. Найдите алгоритмы в *Hyperspectral gaps filler → Raster analysis*
4. Для обработки используйте *Hyperspectral pipeline*

## Требования

- QGIS 3.14 или выше
- Python 3.14
- Обязательные зависимости: `numpy`, `rasterio` ≥ 1.3, GDAL
- Опциональные зависимости: `scipy`, `scikit-image`, `pymap3d`, `pyproj`, `spectral`
